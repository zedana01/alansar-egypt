# موقع شركة الأنصار لمهمات المكاتب (Al-Ansar Egypt)

## 🚀 كيفية إدارة وتعديل ملفات الموقع من جيت هاب (GitHub)

هذا المستودع (Repository) يمثل **لوحة إدارة الملفات (File Manager)** لموقع الأنصار:
1. **تصفح الملفات:** يمكنك الدخول إلى أي مجلد وتصفح صفحات الموقع وصوره.
2. **تعديل أي صفحة:**
   - اضغط على الملف الذي تريد تعديله (مثل `index.html` أو صفحة `اتصل-بنا/index.html`).
   - اضغط على أيقونة القلم ✏️ (**Edit this file**) في أعلى اليمين.
   - قم بإجراء تعديلاتك.
   - اضغط على الزر الأخضر **Commit changes...**.
3. **رفع صور أو ملفات جديدة:**
   - افتح المجلد الذي تريد رفع الملف إليه (مثل `wp-content/uploads/`).
   - اضغط على زر **Add file** ثم **Upload files**.
   - اختر الصور واضغط **Commit changes**.

## ⚡ النشر التلقائي المباشر (Automatic Deployment)
بمجرد حفظ أي تعديل أو رفع أي ملف هنا على GitHub:
- يتم تشغيل **GitHub Actions** تلقائياً.
- يتم إرسال التحديثات مباشرة إلى شبكة **Cloudflare Edge** في خلال **20 إلى 30 ثانية**.
- يظهر التعديل فوراً لجميع الزوار على الدومين الرسمي: `https://alansaregypt.com`.
